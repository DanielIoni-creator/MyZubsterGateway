📖 Style Guide

Linee guida per l'uso coerente del design system nei progetti MyZubster.

🎯 Principi di Design
  • Coerenza: Usa sempre le variabili CSS per colori, spazi e font.
  • Accessibilità: Contrasto minimo 4.5:1 per testo normale, 3:1 per testo grande.
  • Responsive: Tutti i componenti devono funzionare su mobile, tablet e desktop.
  • Performance: Preferisci CSS nativo a librerie esterne quando possibile.
  • Chiarezza: Usa etichette chiare e stati visivi per ogni interazione.

💻 Codice di Esempio
/* MyZubster — Esempio di utilizzo del design system */

/* Importa le variabili nel tuo CSS */
@import "design-system.css";

/* Usa le variabili nei tuoi componenti */
.my-dashboard {
  background: var(--bg-dark);
  color: var(--text-primary);
  border: 1px solid var(--border-default);
}

/* Usa i componenti con classi predefinite */
<button class="btn btn-primary">Salva</button>
<span class="badge badge-success">Pagato</span>
📦 Come Integrare
  1. Includi il file design-system.html nel tuo progetto.
  2. Copia le variabili CSS :root { ... } nel tuo foglio di stile principale.
  3. Usa le classi .btn, .badge, .alert per componenti pronti all'uso.
  4. Per nuovi componenti, segui le convenzioni di naming e spaziatura definite qui.
  5. Mantieni la coerenza visiva usando sempre le variabili CSS invece di valori hard-coded.
