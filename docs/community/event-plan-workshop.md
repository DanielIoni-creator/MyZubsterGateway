# MyZubster Community Event Plan

## Event Type
**Online Workshop** — "Building on MyZubster: From Zero to First Bounty"

## Logistics
- **Date**: TBD (proposed: within 2 weeks of assignment)
- **Duration**: 2 hours
- **Platform**: Discord Stage + YouTube Live
- **Capacity**: 50-100 participants

## Agenda
1. **Intro (15 min)**: What is MyZubster? Gateway & ecosystem overview
2. **Demo (30 min)**: Live walkthrough — register, claim bounty, submit PR
3. **Hands-on (45 min)**: Participants claim a `good-first-issue`, guided setup
4. **Q&A + Networking (30 min)**: Open floor, match devs to bounties

## Promotion Plan
- Announcement on MyZubster Discord & Twitter 1 week before
- Cross-post to bounty-hunting communities
- Direct invites to active contributors

## Participant Management
- Registration via Google Form → Discord role assignment
- Pre-event email with setup instructions (Node.js, Git, GitHub account)
- Post-event survey for feedback

## Success Metrics
- 20+ registered participants
- 5+ new PRs opened within 48h after event
- 3+ new contributors retained

## Budget
- 50 MYZ bounty (event organization)
- Optional: MYZ incentives for best first-time PR during workshop
