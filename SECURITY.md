# Security Tools

## BruteForceAI
Strumento per testare il rate limiting e la protezione da attacchi di forza bruta. **Utilizzare solo in ambiente di sviluppo, mai in produzione.**

## Onionscan
Strumento per verificare la disponibilità del servizio Tor hidden. Utile per testare l'accessibilità dell'endpoint .onion in fase di sviluppo.

**Importante:** Questi strumenti sono esclusivamente per test di sicurezza e non sono richiesti per il funzionamento core del gateway di pagamento.
